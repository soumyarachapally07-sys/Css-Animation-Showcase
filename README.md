**Project Title**
# CSS ANIMATION SHOWCASE

**Project Description**

This project is a simple webpage that demonstrates different CSS animations and transitions. Each animation is clearly displayed and labeled to show how CSS can be used to create interactive and smooth visual effects.

**Technologies Used**

- HTML5
- CSS3
- CSS Animations
- CSS Transitions

## Animations Included

1. Button Hover Effect
2. Growing Box
3. Loading Spinner
4. Bouncing Ball

**Features**

- Hover effects
- Loading spinner animation
- Smooth transitions
- Multiple CSS animations
- Simple and user-friendly layout

# Set Up Instructions

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the "index.html" file in a web browser.
4. The CSS Animation Showcase will be displayed.
5. Hover over the animation elements to see the effects.

# Project Files

- "index.html" – Contains the structure of the webpage.
- "style.css" – Contains the CSS animations, transitions, and styling.
- "README.md" – Contains information about the project.
